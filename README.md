## 工程习惯

- **测试与 CI**：Vitest / Pytest / Playwright，GitHub Actions 门禁，关键逻辑现算可复现。
- **安全基线**：密钥与 `.env` 不入库、最小权限、演示用合成数据或授权环境、MITRE ATT&CK 建模。
- **交付完整度**：README、一键启动脚本、`.env.example`、LICENSE、架构与复盘齐备。
